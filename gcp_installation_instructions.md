# Installing Globus Connect Personal

Before following the training session, users should install Globus Connect Personal (GCP) on their laptop.  
GCP allows you to easily transfer data between your laptop and other servers, by temporarily exposing your PC as a Globus collection (which only you can access).  
It is available for Windows, Linux and Mac. 

You can install and configure Globus Connect Personal as follows: 

### If you are from KU Leuven and you have a KU Leuven managed Windows PC:  
Install Globus Connect Personal via the KU Leuven software center.   
Then, skip to step 1.4 ("After installation has completed...") of the instructions on https://docs.globus.org/globus-connect-personal/install/windows/ to configure your Globus Connect Personal.

### If you do not have a KU Leuven managed windows PC:  
Go to https://www.globus.org/globus-connect-personal.   
Select the desired operating system, and on the next page download the program.  
That page contains detailed instructions for the installation and configuration.  

### Notes on configuration  
For the configuration of your Globus Connect Personal, take the following into account:

- **Collection name:** Choosing a meaningful collection name which will help you recognize your own collection.  
- **High assurance:** We would recommend not to check the option 'High assurance':  
    - The Globus Subscription manager of your institution would need to approve your collection before it will become functional.  
    - High assurance limits a number of actions, some of which are part of the training.
